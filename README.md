# Flower-by-kartikay
The Self-Created Flower project is a creative front-end development exercise designed using only HTML and CSS, with no images, SVGs.

#Project Description:
The Self-Created Flower project is a creative front-end development exercise designed using only HTML and CSS, with no images, SVGs, or JavaScript. The goal of this project is to visually represent a flower by arranging and styling basic HTML elements such as <div> tags, and using CSS to craft petals, a stem, leaves, and the flower center.

In this project, the flower is built by layering multiple circular or elliptical div elements positioned using CSS transforms and absolute positioning. Each petal is typically a colored ellipse with a border-radius, rotated around a central point to form a radial flower pattern. The center of the flower is a circle, styled with background colors and shadows to give it a realistic look. The stem is created using a narrow, tall div with a green background color, and leaves are added using skewed or rotated shapes.

The design relies heavily on CSS properties like:

position: absolute

transform: rotate()

border-radius

box-shadow

background-color

This project demonstrates how CSS can be used not only for layout and styling but also for artistic and geometric compositions. It’s a powerful example of how developers can create visually appealing illustrations using code alone, without any graphic assets.

This flower project helps strengthen understanding of positioning, shape manipulation, and CSS layering techniques. It also encourages creativity and experimentation, making it ideal for students learning front-end design and those who enjoy merging art with code.
